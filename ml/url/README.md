# URL classification

- **Classifier:** `RandomForestClassifier`
- **Training data:** `datasets/url_features_extracted1.csv`
- **Source labels:** `0` = malicious and `1` = benign; training remaps these so
  model class `1` means malicious.
- **Training entry point:** `py -m ml.url.train`
- **Inference inputs and artifact paths:** `inference.py`
- **Model and metrics:** `models/url_fraud_detector.joblib` and
  `models/url_model_metadata.json`
- **Feature extraction:** shared URL feature contract in
  `ml/preprocessing/features.py`; `www.` and an empty root path are normalized
  so equivalent URLs receive identical model features.

`datasets/phiusiil+phishing+url+dataset.zip` is a related source dataset but is
not used by the current training script. `datasets/external_mapped.csv` is
generated by training and is not the source dataset.
